# Version 2.0.0

This release evolves the project from a collection of personal-analysis skills into an integrated Personal Intelligence system. It retains the 14 skills and adds a canonical profile model, 12 domain modules, analysis and strategy engines, reusable prompts, private data templates, schema contracts, and repository tests.

## Known limitations
Tests check repository structure and JSON parseability/contracts using Python's standard library. They do not replace full JSON Schema validation or end-to-end testing in a live model session.
