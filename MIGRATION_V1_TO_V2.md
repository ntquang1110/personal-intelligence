# Migration Guide: v1 → v2

Version 2 retains the 14 original skills and integrates them with a canonical profile, 12 domain modules, shared evidence rules, analysis engines, schemas, and feedback loops.

1. Back up the v1 repository.
2. Copy only personal notes you intend to preserve; do not treat old conclusions as verified facts.
3. Initialize from `templates/profile.template.json` and `templates/evidence.template.json`.
4. Re-enter findings with original source/date when available; mark unsupported interpretations as hypotheses.
5. Link evidence to domains D01–D12.
6. Generate a provisional overview and prioritize high-impact evidence gaps.
7. Keep populated personal data out of public Git history.

Domain IDs: D01 identity and values; D02 life history; D03 cognitive style; D04 behavior and execution; D05 strengths; D06 career; D07 family; D08 friends/social; D09 finance/resources; D10 lifestyle/energy; D11 life strategy; D12 evolution.

Do not blindly carry a v1 personality conclusion into v2. Preserve its source, context, confidence, and counterevidence so it can be reviewed.
